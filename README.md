# Argelo Cumayas Nuñez

Co-founder and systems strategist at [Spawntel](https://spawntel.com). I build
agent workflow systems, automation pipelines, and live-commerce tooling — mostly
local-first, mostly dependency-light, always with a written trail of what ran.

## Selected work

**[thrift-go](https://github.com/Arvoszn/thrift-go)** — a sales console for Instagram
live comment auctions: bids arrive as comments, only a claim locks an item,
the winner gets the price ladder and payment instructions in a private reply,
then payment review and fulfilment are tracked in one place. Built for a live
reseller and published as a portfolio reference.

**[agent-dispatch](https://github.com/Arvoszn/agent-dispatch)** — the dispatch layer
I use to keep several agents on one job: explainable routing with a confidence
floor, hard step budgets, an append-only run log, and a handoff at the end of
every run. Zero dependencies, runs offline against a stub model.

**[lifeplanner](https://github.com/Arvoszn/lifeplanner)** — a local-first daily
planner with recurring tasks, deadlines, and Windows toast reminders. Plain Node
and one JSON file; no account, no database, no `npm install`.

Also here: coursework in Java (data structures, OOP) kept as-is, and a few
smaller builds.

## How I work

- **Written down or it did not happen.** Decisions, runs, and handoffs get
  recorded — that is how work survives a session ending mid-task.
- **Refuse to guess.** An unroutable request should produce a named gap, not a
  confident-sounding answer.
- **Local-first where it fits.** Fewer moving parts, fewer accounts, less to
  break at 2am.
